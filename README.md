# Al Ghifari Solution – Katalog Website

## Cara Menjalankan Download 117 Foto Otomatis di GitHub

1. Ekstrak seluruh isi file ZIP ini dan upload ke folder utama (root) repository GitHub Anda (pastikan folder `.github/workflows/download-foto.yml` ikut ter-upload).
2. Buka tab **Actions** di repository GitHub Anda.
3. Pilih workflow **Download Foto Produk** di menu sebelah kiri.
4. Klik tombol **Run workflow** > **Run workflow** dan tunggu sekitar 1–2 menit hingga selesai.
5. Semua 117 foto `.jpg` akan otomatis tersimpan di folder utama repository, kolom **Foto Sudah Ada?** di `daftar-produk.xlsx` terisi `Ya`, dan website `index.html` akan langsung menampilkan foto produk secara otomatis.
