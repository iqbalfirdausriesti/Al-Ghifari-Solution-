# Al‑Ghifari Solution – Gadget Store

A lightweight static site showcasing a catalogue of smartphones, laptops and accessories.  
The site is built with plain HTML, CSS and a tiny amount of JavaScript – no build step is required.

## Features
- **Responsive design** – grids for brand logos (`.br`) and quick links (`.qk`) use `repeat(auto‑fit, minmax(...))` so the layout adapts to phones, tablets, laptops and desktops.
- **Uniform brand‑logo sizing** – all logo SVGs are rendered at the same visual height (48 px) with `object‑fit: contain`.
- **Client‑side search** – the header search bar filters the catalogue without any server code.
- **GitHub Pages ready** – simply push to the `main` branch and GitHub Pages will serve the site.
